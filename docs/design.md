# 0.4.0 조회 전용 동작

현재 실행 경로는 app → query_monitor입니다. 이전 monitor의 과 순환 코드는 사용하지 않습니다.
사용자는 EMR의 과와 의사를 직접 선택하고 조회 버튼 영역 하나만 지정합니다.
감시 경로는 OCR를 생성하거나 과/의사 선택 함수를 호출하지 않습니다.
조회 → 3초 대기 → 캡처 → 2초 대기 → 캡처 → 안정성 비교 → 변경 전송 순서입니다.
격자 기반 분류 실패는 일반 화면 비교로 대체됩니다. 첫 안정 화면은 기준이며 전송 실패 시 기준을 갱신하지 않습니다.

시작 캡처와 명령 캡처는 비교 기준을 바꾸지 않습니다. 명령 처리는 감시 스레드에서 순차 수행하며 고정 수신 그룹만 허용합니다. 시작 이후 메시지만 처리하고 update offset으로 중복을 방지합니다. UI는 감시 중 최소화해 작업표시줄 상태를 유지합니다. 기존 설정 저장 경로는 호환성을 위해 유지합니다.
