# 수술방 알림봇 · ORAlertBot 0.3.0

사람이 선택한 EMR 수술 목록에서 **조회 버튼만** 반복해서 누르고, 화면이 변경되면 Telegram 그룹에 캡처를 보냅니다. 진료과·진료의 선택이나 이름 인식은 하지 않습니다. 감시에 OCR가 필요하지 않습니다.

## 사용 순서

1. 기존 봇을 종료하고 ZIP을 압축 해제한 후 `ORAlertBot.exe`를 실행합니다.
2. EMR에서 진료과·진료의·날짜 등 조회 조건을 직접 선택합니다.
3. 봇에서 대상 창을 선택하고 **조회 버튼 위치 지정**을 누릅니다. 표시된 캡처에서 조회 버튼만 드래그합니다.
4. 조회 간격을 지정합니다. 최소 30초, 기본 60초입니다.
5. 텔레그램 연결 탭에서 토큰과 그룹을 설정하고 테스트 메시지로 확인합니다.
6. 실제 전송하려면 **로컬 시험 모드 체크를 해제**하고 감시 시작을 누릅니다.
7. F8로 중지합니다. 조회 조건을 바꾸려면 중지 후 EMR에서 변경하고 다시 시작합니다.

설정 저장 버튼으로 토큰·그룹·조회 위치를 저장할 수 있습니다. 이전 버전의 진료과 설정은 사용하지 않습니다.

## 변경 감지

- 첫 안정된 조회 결과는 기준 화면으로 저장합니다. 이후 2초 간격의 두 캡처가 일치할 때 변경을 비교합니다.
- 수술 표 격자가 인식되면 표 영역을 비교합니다. 행 추가·삭제·환자상태 변경은 주요, 기타 수정은 세부로 분류합니다.
- 표 구조나 행 분류가 불가능해도 중단하지 않습니다. 조회 버튼 아래 화면 또는 감지된 표를 비교하고 일반 변경 알림과 전체 EMR 캡처를 보냅니다.
- 분류는 보조 정보입니다. 실제 시작·종료는 예정시각으로 추측하지 않습니다.
- 현재 보이는 화면만 감시합니다. 숨겨진 행·다른 페이지·다른 진료과를 순회하지 않습니다.
- 화면 렌더링이나 자동 증가하는 시간이 바뀌어도 알림이 발생할 수 있습니다.
- 최소화·가림·창 크기 변경·동작 중 사용자 입력은 중단 사유입니다. 크기가 바뀌면 조회 위치를 다시 지정합니다.
- 일시적 전송 실패는 메모리의 캡처를 재시도합니다. 전송 성공 후 비교 기준을 갱신합니다. 응답 유실 시 중복 알림이 가능하며 종료하면 미전송 캡처는 사라집니다.

## Telegram 오류 해결

**연결 진단**은 `getMe`로 서버·토큰을 확인한 후 `getWebhookInfo`로 기존 연동 여부를 확인합니다. 웹훅을 임의 삭제하지 않습니다.

| 코드 | 의미와 조치 |
|---|---|
| TOKEN | BotFather API 토큰 전체를 다시 입력합니다. 사용자 이름이나 앞의 `bot` 문자열을 넣지 않습니다. |
| CHAT_NOT_FOUND | 봇을 그룹에 추가하고 그룹 찾기로 Chat ID를 다시 선택합니다. |
| FORBIDDEN | 그룹 참여 여부와 메시지·파일 전송 권한을 확인합니다. |
| CONFLICT | 같은 봇을 쓰는 중복 프로그램을 종료합니다. 웹훅 충돌이면 기존 연동에서 해제하거나 Chat ID를 직접 입력합니다. |
| DNS / NETWORK / TIMEOUT | 병원 PC에서 `api.telegram.org:443` 접속 가능 여부를 확인합니다. |
| TLS_CERT / TLS | PC 시간과 병원 프록시 인증서 구성을 확인합니다. 인증서 검증을 끄지 않습니다. |
| RATE_LIMIT | 표시된 시간 후 재시도합니다. |
| MIGRATED | 화면에 표시된 새 그룹 ID를 입력합니다. |

토큰 없이 이 개발 PC에서 Telegram HTTPS 기본 접속은 확인했습니다. **사용자 토큰 인증과 그룹 전송은 별도 확인이 필요합니다.**

## 저장 및 개발

설정은 `%LOCALAPPDATA%\ORAlertBot\settings.bin`에 Windows 사용자 키로 암호화합니다. 환자 캡처는 메모리에서만 처리하며 GitHub와 EXE에 포함하지 않습니다. Telegram으로 전송된 이미지는 그룹에 남습니다.

Windows x64 + Python 3.12에서 `pip install -r requirements-build.txt`, `python -m unittest discover -s tests -v`, `python run.py`로 개발 실행합니다. `build.ps1`로 폴더형 EXE와 ZIP을 생성합니다.

실제 병원 EMR 조회와 Telegram 그룹 전송은 현장 확인이 필요합니다.
