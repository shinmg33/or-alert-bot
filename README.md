# 수술방 알림봇 · ORAlertBot

Windows 설치형 EMR 수술 목록을 주기적으로 조회하고 변경 시 텔레그램 비공개 그룹에 원본 PNG 캡처를 보내는 내부 사용용 프로그램입니다.

**0.1.0 시험 버전입니다. 실제 EMR의 캡처와 진료과 선택은 현장 검증이 필요합니다.** 소스·실행 파일에 환자정보와 봇 토큰을 포함하지 않습니다.

## 기능

- Windows GUI: 텔레그램 연결, 감시 설정, 화면 영역 지정
- 여러 진료과 순환 조회, 진료의 전체 확인, 최소 30초·기본 60초 간격
- Windows 한국어 OCR로 로컬 표 인식 (외부 OCR 서비스 미사용)
- 주요 변경: 신규 행, 환자상태 변경, 목록에서 사라진 행
- 세부 변경: 예정 시작시간, 소요시간, 수술방 등 다른 항목 수정
- 같은 화면과 단순 정렬 변경 제외, 과별 기준 분리, 최초 조회는 기준만 생성
- 두 번 읽은 결과가 일치하고 총 건수와 인식 행 수가 맞을 때 비교
- 원본 PNG 전송, 세부 변경 무음 옵션, 환자정보 없는 연결 테스트
- Windows DPAPI로 설정 암호화, 로컬 시험 모드, F8 중지

## 빠른 시작

1. ZIP을 풀고 **폴더 전체를 유지**한 채 `ORAlertBot.exe`를 실행합니다. 별도 Python 설치는 필요 없습니다.
2. Windows 한국어 OCR 언어팩이 필요합니다. 없으면 Windows 언어 설정에서 설치합니다.
3. **텔레그램 연결** 탭에 BotFather 토큰을 입력합니다. 토큰을 채팅·GitHub에 올리지 않습니다.
4. 동료 그룹에 봇을 추가하고 그룹에서 `/start`를 보냅니다. **그룹 찾기**로 대상을 선택하고 **테스트 메시지 보내기**로 수신을 확인합니다.
5. 사람이 EMR 수술 목록을 열고 날짜·수술상태·수술방 필터를 설정합니다.
6. **감시 설정**에 `진료과 이름=드롭다운 순번`을 한 줄씩 입력합니다. 맨 위가 0입니다. 실제 목록을 보고 입력하세요.
7. **화면 설정 → 현재 화면 가져오기**를 누른 후 4초 안에 EMR 목록을 맨 앞으로 둡니다.
8. 캡처 위에서 진료과 상자, 진료의 상자, 조회 버튼, 날짜 글자만, 총 건수 숫자만, 표 전체, 수술상태 라디오 버튼 전체, 수술방 필터를 각각 드래그합니다. 표에는 머리글과 모든 행을 포함합니다.
9. 등록번호·수술명·환자상태의 **머리글 셀 전체**를 각각 지정합니다. 셀 좌우 경계와 머리글 아래 경계에 맞춥니다.
10. 영역과 순번 확인란을 선택하고 설정을 저장합니다. **로컬 시험 모드로 먼저 시작**하고 5초 안에 EMR을 맨 앞으로 둡니다.
11. 실제 과 선택·캡처·인식을 확인한 뒤 중지하고 로컬 시험 모드를 해제하면 Telegram에 전송합니다.

항상 중지 상태와 로컬 시험 모드로 실행됩니다. 자동 로그인·자동 시작은 없습니다.

## 동작 범위와 제한

- 입력 대상은 **진료과·진료의·조회**뿐입니다. 날짜·다른 버튼·환자 행은 조작하지 않습니다. EMR 파일을 수정하지 않습니다.
- 과 선택은 상자 클릭 → Home → 지정 횟수 아래 방향키 → Enter 방식입니다. 해당 EMR에서 작동하는지 검증해야 합니다. 과 이름이 맞지 않으면 조회하지 않습니다.
- EMR 창을 맨 앞으로 유지해야 합니다. 잠금·최소화·가림·창 크기 변경·감시 동작 중 사용자 입력 시 중단합니다. 캡처 방지 기능을 우회하지 않습니다.
- **이전 자동화 도구의 창 캡처는 시간 초과가 있었습니다. 이 버전의 화면 캡처 방식도 병원 PC에서 아직 검증되지 않았습니다.**
- 날짜는 사람이 선택한 값으로 고정합니다. 날짜·수술상태·수술방 조건이 바뀌면 중단합니다. 전체 상태 감시를 원하면 사람이 수술상태를 전체로 설정합니다.
- 간격은 과 하나에서 다음 과로 넘어가는 조회 간격입니다. 2개 과·60초이면 각 과는 약 120초마다 확인합니다. OCR·전송 지연 시 더 늦어집니다.
- **스크롤 아래 숨겨진 행, 여러 페이지, 여러 줄 셀은 지원하지 않습니다.** 총 건수와 읽은 행 수가 다르면 중단합니다.
- 등록번호와 수술명으로 행을 대응합니다. 중복 수술·수술명 수정은 판정이 모호하다고 알립니다. OCR가 두 번 동일하게 틀릴 수 있어 캡처로 확인해야 합니다.
- 시작시간은 예정 시각입니다. 실제 상태는 환자상태 글자 변경으로 알립니다. 행 사라짐을 취소·종료로 단정하지 않습니다.
- 소요시간 등 세부 항목을 모두 비교합니다. EMR이 시간을 자동 증가시키는 경우 세부 알림이 반복될 수 있습니다. 항목 제외 설정은 후속 기능입니다.
- 전송 실패 시 조회를 멈추고 메모리에 있는 캡처를 30초마다 재시도합니다. 응답 유실 시 중복 수신 가능성이 있습니다. **중지·종료·재시작 시 기준과 미전송 캡처는 사라집니다.**
- 중지 전에 시작된 네트워크 전송은 취소되지 않을 수 있습니다.

## 저장

`%LOCALAPPDATA%\ORAlertBot\settings.bin`에 현재 Windows 사용자 키로 설정을 암호화합니다. 다른 PC·계정에서는 다시 설정합니다. 같은 Windows 계정으로 실행되는 프로그램까지 차단하는 장치는 아닙니다.

캡처·OCR 원문·환자 행은 메모리에서만 처리합니다. 전송한 PNG는 Telegram 그룹에 남습니다. 요청한 대로 식별번호를 가리지 않습니다. GitHub에는 실제 화면을 넣지 않습니다.

## 개발과 빌드

Windows x64 + Python 3.12:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-build.txt
python -m unittest discover -s tests -v
python run.py
.\build.ps1
```

산출물: `dist/ORAlertBot/ORAlertBot.exe`, `dist/ORAlertBot-windows-x64.zip`.
한국어 OCR 언어팩은 ZIP에 포함하지 않습니다. 실행 파일은 서명되지 않았습니다.

가상 데이터 테스트는 실제 EMR·Telegram 현장 검증을 대체하지 않습니다.
